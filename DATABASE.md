# PINO Team OS data authority

Core is authoritative for Access User/Staff linkage, Staff profile, Operating Cycle, Shift Templates and final Assignments, Availability, Timekeeping, and Policy Center decisions. Team OS accesses those capabilities only through private Core service bindings and never queries Core D1.

Notion remains available only for explicitly unmigrated domains such as Companion/Pinoria, training, programs, and other separately governed content. It is not a runtime source or fallback for Staff/Workforce operations.
